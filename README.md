# Bella's Restaurant Demo

Premium restaurant website concept based on the Bella's photos provided in the conversation.

## Run
Open `index.html` in a browser.

## Before showing the owner
Replace:
- Demo food names/prices in `index.html`
- `03XX-XXXXXXX`
- `hello@bellas.com`
- `923XXXXXXXXX` in `script.js`
- Google Maps destination if needed

The website includes:
- Responsive homepage
- Menu filtering
- Add-to-cart
- Cart drawer
- WhatsApp order flow
- Gallery
- Contact/location section
- Scroll animations

Updated food visuals: a clean pizza crop and Bella's existing signature steak photo are used; the ice-cream and noodles/pizza originals were removed.

Pizza and burger demo visuals use Unsplash image URLs and require internet access when the page is opened. Bella's supplied steak, drinks, interior and exterior visuals remain local assets.
